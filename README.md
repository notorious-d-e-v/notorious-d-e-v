# 👋 Hey, I'm the Notorious D.E.V.

Founder of [PayAI](https://payai.network). I build payment infrastructure that lets AI agents, APIs, and apps get paid — with a focus on x402, Solana, and reliable settlement.

## What I'm working on

- **[PayAI x402 facilitator](https://payai.network)** — stablecoin payment verification and settlement for agents and apps across Solana and supported EVM networks. No API key needed to start; agents can [buy their own key over x402](https://docs.payai.network/x402/facilitators/agent-api-keys), get discovered through the [Bazaar](https://docs.payai.network/x402/facilitators/bazaar), and pay transparent [cost-plus pricing](https://docs.payai.network/x402/facilitators/pricing). [Start here](https://docs.payai.network/x402/quickstart).
- **[Solana batch settlement](https://github.com/PayAINetwork/x402-batch-preview)** — a PayAI preview for high-volume x402 payments. The latest release adds a merchant-authenticated seal with payout recovery and a published deprecation policy; integration and recovery guidance is in the [docs](https://docs.payai.network/x402/servers/batch-settlement).
- **Upstream x402** — [29 merged PRs](https://github.com/x402-foundation/x402/pulls?q=is%3Apr+author%3Anotorious-d-e-v+is%3Amerged) to x402-foundation/x402 (Solana `exact` scheme, `upto` scheme, operator-configurable facilitator limits, facilitator-client timeouts, a Solana CloudFront example), plus batch-settlement recovery fixes in [solana-foundation/x402](https://github.com/solana-foundation/x402/pulls?q=is%3Apr+author%3Anotorious-d-e-v).
- **[DividendX](https://github.com/notorious-d-e-v/dividendx-stocklana)** — a Solana devnet hackathon prototype that separates tokenized-stock principal from dividend rights. [Try the guided demo](https://dividendx.payai.network/demos/).
- **[Agent skills](https://github.com/notorious-d-e-v/agent-skills)** — reusable skills for coding agents, installable one at a time.

Want to test an x402 client? Try the [Echo Merchant](https://x402.payai.network).
